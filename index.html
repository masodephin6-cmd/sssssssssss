Deterministic Lockstep / Snapshot-Ready Architecture

This engine strictly decouples Game.Simulation from Game.Renderer and Game.Tank3D:

  • InputFrame Command Pipeline: Local player, AI bots, and future remote network peers all produce an identical InputFrame { tick, moveX, moveY, aimX, aimY, pressedMask, heldMask, releasedMask, castSkillSlot, castAimX, castAimY, buyItemId }.
  • Seeded PRNG: Inside Game.Simulation, Math.random is never called. All crits, bullet spread, creep spawns, and AI tie-breakers use Game.Math.SeededPRNG stored inside the serializable state.
  • State Serialization: Press during or before a match to verify full JSON state round-tripping.
